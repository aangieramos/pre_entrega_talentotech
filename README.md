# Proyecto Web - Landing Page

Este proyecto es una página web responsiva desarrollada con HTML5 y CSS3 semántico como parte de la entrega del curso de Frontend.

## Contenido del sitio
- **Inicio:** Presentación de la marca o servicio.
- **Productos:** Catálogo con tarjetas estructuradas mediante Flexbox.
- **Reseñas:** Testimonios organizados con CSS Grid.
- **Contacto:** Formulario funcional integrado con Formspree.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 (Flexbox, CSS Grid y Media Queries)
- Google Fonts
- Formspree para envío de correo
